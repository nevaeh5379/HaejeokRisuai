## Existing fork behavior

- Svelte is already at 5.57.2, newer than upstream's 5.56.8; existing dependency versions remain in place.
- Chat rerolls already store only appended messages through the branch/message store. The upstream full-history clone path does not exist here.
- Character and plugin-storage reads already use SQL-aware snapshots/per-key reads rather than whole-database snapshots.
- Module creation already installs once through `moduleStore.installModule`; the upstream duplicate-push path does not exist here.
- Runtime legal configuration is already checked in the app shell and alert implementation.
- Startup and internal backups use SQL revisions; the upstream automatic `database.bin` backup recovery loop is absent. Legacy local-save imports remain supported.
- Risu Account sync and Google Drive integrations were removed from the fork. Account-sync cancellation and those services' save lifecycle changes do not apply.
- The original `server.cjs`, nightly publishing workflow, PR template, and upstream version metadata are superseded by this fork's typed server, CI, and `bNNNN` build numbering.

## Import boundaries

Use an exported local backup when migrating upstream plugin data. A raw `database.bin` can reference cold storage or remote block files that are only present on its original device. Node rejects unresolved remote blocks instead of silently restoring an incomplete database. Missing index/large plugin values fail restoration. SaveKV namespaces are preserved as imported data; the fork continues to persist its live state through SQL.
